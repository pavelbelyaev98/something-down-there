# Crystal cracks
- **Item:** `CrystalCracks.png`, a 1024 px tiling mask of branching fracture lines whose alpha orders when each line appears.
- **Purpose:** the crack overlay on a crystal cavern cluster (`115`): `CavernCrystal` lowers the clip threshold as the tool works it, so fractures spread and branch, glowing, until it bursts.
- **Source/License:** original, generated by `make_cracks.py` (run from the repository root; Pillow and numpy). No external content.
- **Unity path:** `Assets/Content/Caverns/CrystalCracks.png` in `CrystalCracks.mat`, both set up by **Configure Caverns**.
- **Status:** integrated in MainGame.
