# UI fonts
- **Item:** Lilita One (Regular) and Barlow Condensed (Medium, SemiBold) TrueType fonts.
- **Purpose:** Menu screens (`Screens.uss`): Lilita One sets the logo, title and pause entries, settings tabs, headings and buttons; Barlow Condensed sets settings rows, values and descriptions.
- **Source/License:** Google Fonts (`github.com/google/fonts`, `ofl/lilitaone`, `ofl/barlowcondensed`); SIL Open Font License 1.1, commercial use allowed. Lilita One © 2011 Juan Montoreano; Barlow © 2017 The Barlow Project Authors. The license texts sit beside the fonts; list both in the game's credits before release.
- **Unity Path:** `unity/Assets/Content/UI/Fonts/` (`LilitaOne-Regular.ttf`, `BarlowCondensed-Medium.ttf`, `BarlowCondensed-SemiBold.ttf`, `*-OFL.txt`), referenced by `url()` from `Screens.uss`.
- **Status:** In use (menu redesign `117`, on trial).
