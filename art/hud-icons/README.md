# HUD icons
- **Item:** Four flat glyphs: battery bolt, stack of banknotes, canvas bag, work lamp.
- **Purpose:** The HUD's resource readouts (money, bag, lamps, battery bar).
- **Source/License:** Original; vector shapes drawn at runtime by `HudIcons` (Painter2D). No external content, no texture files.
- **Unity Path:** `unity/Assets/Runtime/UI/Toolkit/HudIcons.cs`, placed by `GameHud.uxml` / `Hud.uss`.
- **Status:** In use (on trial with the menu redesign `117`); replaceable by a bought icon set.
