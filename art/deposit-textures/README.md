# Asset: Deposit Textures — Gravel & Concrete

- **Item:** Tileable gravel (stacked rounded stones over dark fines) and concrete (cement, aggregate, pores) ground surfaces: albedo, normal and occlusion (G) mask, 1024².
- **Purpose:** Cut faces of the gravel and diggable-concrete deposits in the triplanar ground shader; the approved packs have neither surface.
- **Source/License:** Original, generated by project editor code (`unity/Assets/Editor/DepositTextures.cs`); no third-party content.
- **Unity Path:** `unity/Assets/Content/GroundTextures/Gravel_*.png` and `Concrete_*.png`, bound on `Content/Nature/ReservoirSediment.mat` by `GroundTextureSetup.ConfigureDeposits`.
- **Status:** In use. Delete a set's PNGs and run *Tools › Something Down There › Configure Ground Deposits* to regenerate it.
