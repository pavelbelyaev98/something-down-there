# Tower crane pack
- **Item:** user-purchased tower crane pack (models, textures, Built-in Standard materials, controller scripts, two demo scenes); the weathered `TC_old_Base_small` crane (the pack's smallest) is the game's salvage crane.
- **Purpose:** the yard's salvage machine: its own hook rides its rope down the player's hole and tunnel into a lifting eye, and it carries recovered uniques to the camp.
- **Source/License:** user-purchased; store link and licence not yet recorded (add them here). Private repository; binaries in Git LFS.
- **Unity path:** vendor files unmodified in `Assets/TowerCrane`; project variant `Assets/Content/Salvage/SalvageCrane.prefab` and URP Lit copies of the used materials and a copy of the jib mesh without the hoist cable (`towerCrane_boom_small without hoist cable.asset`) in `Assets/Content/Salvage/Crane`, all regenerated by **Configure Salvage Crane**. The cable's two falls are rebuilt at runtime (`CraneRopeView`) as the pack's hexagonal strands, with its measured ends, radius, jib material and texture strip, so they can bend into a tunnel.
- **Integration:** the vendor `Controller_TC`/`Hook` scripts are removed from the variant (legacy `Input`, player keys, world-height hook floor); `TowerCraneRig` applies the same motion to the same rig. Demo scenes stay as references.
- **Status:** integrated in MainGame.
