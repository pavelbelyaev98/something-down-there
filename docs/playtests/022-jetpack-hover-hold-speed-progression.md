# Playtest 022 — Jetpack Hover Hold & Speed Progression

**Build & start:** current build, New Game (saves from before this build no longer load). Developer admin → Add $500 helps buy Jetpack levels quickly.

## Try
- Fly home from depth on the starter jetpack, then buy Jetpack levels at the computer and fly again.
- In a narrow shaft, stop halfway up and dig a side tunnel while hovering; then fly out and land at
  the rim.

## Good feels like
- Stable and easy at every level; each purchase climbs clearly faster and drains less battery.
- Hover holds you steady; landing at the rim is never fiddly; walls never knock you around.

## Compare (A/B)
- Developer admin (Ctrl+Shift+F10) → **Hover: while digging / on release**.
  - While digging (default): you hover only while holding dig in the air; let go and you fall.
  - On release: letting go of Space hovers anywhere; hold crouch to drop.

## Tell the agent
- Which hover mode won, and whether the top speed (17 m/s) is comfortable in a narrow shaft.
