# Playtest 001 — Evolving Motorized Tool Rig

**Build & start:** current build, New Game. Buy Tool levels at the computer, or use Ctrl+Shift+1…9, 0
to preview every level.

## Try
- Dig soil, gravel, clay, rock and concrete with the early shovel, then with the drill (level 7+).
- Buy a Tool level and close the computer: the machine should already look different.
- Hold a find, place a lamp, mark a unique for recovery: the tool should get out of the way.
- Change the field of view in Settings; crouch into a tight tunnel and dig against its walls.

## Good feels like
- One machine growing ridiculous: shovel, bolted-on motor and batteries, a drill, finally a cannon.
- Strokes feel different per ground (wide scoop in soil, short bites in clay, hard jabs in rock); the
  drill spins and chatters while cutting; the camera itself never moves.
- It never covers the crosshair or what you are digging, and never sticks through a wall.

## Tell the agent
- Any stage that reads poorly, whether size and placement feel right, whether the motion is too much
  or too little, and any clipping.
