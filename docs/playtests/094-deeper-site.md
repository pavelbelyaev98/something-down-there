# Playtest 094 — Deeper Site (150 m)

**Build & start:** current `builds/windows/SomethingDownThere.exe`, New Game. Developer shortcuts
are fine: Ctrl+Shift+0 (final tool level), Developer admin → Unlimited battery.

## Try
- Dig down well past the old 100 m floor, to about 150 m.
- Stop every 20–30 m and dig around for a minute: do finds keep turning up?
- At depth, let the game save, quit, Continue, and dig straight away.

## Good feels like
- No empty stretch anywhere down the shaft; finds come at a steady rate to the bottom.
- Saving never stutters; a deep save reloads in about 3 seconds and the first dig is instant.

## Tell the agent
- Any depth band that felt empty, and any hitch while saving, loading or digging.
